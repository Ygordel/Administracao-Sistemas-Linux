🎯 Sobre o Curso
O curso de Administração de Sistemas Linux apresenta os principais fundamentos necessários para compreender, gerenciar e configurar ambientes Linux.

Durante a formação são trabalhos conceitos relacionados aos usuários, sistema de arquivos, processos, logs, impressão, backup, inicialização, kernel, segurança e gerenciamento do sistema.

O conteúdo é organizado em 10 módulos , permitindo uma evolução progressiva entre os conceitos fundamentais e as atividades práticas.
